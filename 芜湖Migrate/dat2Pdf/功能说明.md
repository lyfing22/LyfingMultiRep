# dat2pdf — 东软 DAT 转 PDF 工具

## 简介

将东软（Neusoft）医疗信息系统导出的 `.dat` 报告文件批量转换为标准 PDF 文档，用于数据迁移或归档。

## 核心功能

1. **DAT → JPG** — 调用 `ConvertReport2Image.exe` 将东软 DAT 报告解析为 JPG 图片（支持多页）。
2. **JPG → PDF** — 使用 `img2pdf` 将 JPG 图片合并为无损 PDF（保留原始像素尺寸）。
3. **批量处理** — 自动遍历根目录下按日期命名的子文件夹（如 `20230522`），递归处理所有 `.dat` 文件。
4. **断点续传** — 已生成 PDF 或 JPG 的文件自动跳过，支持中断后重新运行。
5. **失败记录** — 转换失败的文件记录到 `conversion_failures.xlsx`，包含失败阶段、错误信息、尝试次数、首次/最后出现时间。文件达到 10,000 行自动归档。

## 工作流程

```
.dat 文件
    ↓
ConvertReport2Image.exe（东软 DLL + 脚本引擎）
    ↓
*.jpg（多页图片）
    ↓
img2pdf（无损合并）
    ↓
.pdf 文件（与 DAT 同目录）
```

## 配置方式

配置优先级（从高到低）：

1. **命令行参数** — `dat2pdf.exe D:\path\to\data`
2. **环境变量** — `DAT2PDF_ROOT=D:\path\to\data`
3. **config.json** — 程序目录下
4. **内置默认值**

### config.json 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `root` | `D:\Migrate\Report_Data` | DAT 文件根目录 |
| `exe_dir` | `dat2Img` | ConvertReport2Image.exe 所在目录 |
| `exe_name` | `ConvertReport2Image.exe` | 转换工具可执行文件名 |
| `max_rows` | `10000` | Excel 日志最大行数（超限自动归档） |
| `timeout_sec` | `120` | 单个 DAT 转换超时时间（秒） |

## 目录结构要求

```
D:\Migrate\Report_Data\
├── 20230522\
│   ├── RPT1234567890ABCDEF.dat
│   └── ...
├── 20230523\
│   └── ...
└── ...
```

- 子文件夹名称必须为 8 位纯数字（如 `20230522`），代表日期。
- DAT 文件名格式为 `RPT<报告ID>v<版本号>.dat`。

## 构建

运行 `build.bat`，使用 PyInstaller 打包为独立可执行文件：

```bash
build.bat
```

产物输出到 `dist\dat2pdf\` 目录。

## 依赖

- Python 3.13+
- img2pdf
- openpyxl
- ConvertReport2Image.exe（东软报告转换工具，位于 `dat2Img/` 目录）

## 使用示例

```bash
# 使用默认配置
dat2pdf.exe

# 指定根目录
dat2pdf.exe D:\my_data

# 通过环境变量指定
set DAT2PDF_ROOT=D:\my_data
dat2pdf.exe
```
